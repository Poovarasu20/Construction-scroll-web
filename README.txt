VANGUARD STRUCTURAL — SCROLL-SYNCHRONIZED CONSTRUCTION WEBSITE

FILES
- index.html: complete website, including styling and JavaScript
- assets/construction.mp4: construction video extracted from the original HTML's embedded video

RUN ON WINDOWS
1. Extract this ZIP to a folder.
2. Open that folder in VS Code.
3. Recommended: install the Live Server extension, right-click index.html, and choose Open with Live Server.
   Or open a terminal in this folder and run: python -m http.server 8000
   Then visit http://localhost:8000
4. Scroll down through the five construction stages. Scroll up to scrub backward.

NOTES
- Keep assets/construction.mp4 in the assets folder so the relative video path works.
- The website loads Tailwind CSS, Lucide icons, and fonts from the internet, so those external resources need connectivity.
- The page includes an Auto Timelapse control; switch it off to use scroll-synchronized playback.
